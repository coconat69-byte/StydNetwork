# СтудСеть

Закрытая учебная соцсеть колледжа: чаты по группам и направлениям, каналы преподавателей, поиск людей и клубы по интересам.

Сайт на HTML, CSS и JavaScript с backend-ом на Go и базой SQLite.

## Дисклеймер

СтудСеть — учебный проект. Сайт создан исключительно в образовательных целях, не является коммерческим продуктом и не используется в коммерческих целях. Все материалы и данные носят демонстрационный характер и не предназначены для реальной эксплуатации.

Проект не связан с официальными сервисами учебных заведений и не собирает персональные данные в коммерческих интересах. Авторы не несут ответственности за использование материалов вне учебного контекста.

Распространяется «как есть» (as-is).

## Возможности

- вход по личному коду доступа (свободная регистрация недоступна);
- чаты: группы, направления, курсы, каналы и личные сообщения;
- поиск студентов по группе, направлению, курсу и статусу «онлайн»;
- клубы по интересам;
- профиль и настройки (тема, уведомления, приватность);
- админ-панель для администратора: каналы, объявления, блокировка пользователей и жалобы.

## Стек

- **Фронтенд:** HTML5, CSS3, JavaScript. Страница — `index.html`, стили — `css/`, интерфейс — `js/app.js`, откуда брать данные — `js/api.js`, тема до отрисовки — `js/theme.js`.
- **Как всё устроено:** подробности в файле [ДОКУМЕНТАЦИЯ.md](ДОКУМЕНТАЦИЯ.md) — экраны, вход, данные, сервер, все адреса API, таблицы базы и защита.
- **Данные:** все стартовые данные лежат в одном файле — `js/data.js`. Менять их нужно только там.
- **Backend:** Go (`back/`). `main.go` — запуск и список адресов, `api.go` — обработчики `/api/...`, `db.go` — работа с базой.
- **База данных:** SQLite, один файл `back/studnet.db`. Таблицы описаны в `back/schema.sql`, при первом запуске сервер заполняет их из `js/data.js`.

## Запуск

Коды для входа (дефисы ставятся сами):

- `123-123-123` — студент Яша Кузнецов;
- `456-456-456` — администратор Ольга Сидорова (есть админ-панель);
- `789-789-789` — преподаватель Артём Досиксов.

**С сервером** (нужен [Go](https://go.dev/dl/) версии 1.22 или новее):

```bash
cd back
go run .
```

Откройте http://localhost:8080 — или откройте `index.html` как обычно (Live Server, двойной щелчок): сайт сам подключится к серверу на `localhost:8080`. Сообщения, личные чаты и вступления в клубы сохраняются в базе.

**Без сервера** сайт тоже работает: если `go run .` не запущен, данные берутся прямо из `js/data.js`. В этом режиме всё, что вы изменили, живёт до обновления страницы.

База создаётся сама при первом запуске. Чтобы вернуть её к стартовым данным (например, после правки `js/data.js`), остановите сервер, удалите `back/studnet.db` и запустите снова.

## Безопасность

- защита от XSS: всё, что вводят пользователи, экранируется перед выводом, а сервер включает Content-Security-Policy;
- защита от SQL-инъекций: все запросы к базе с параметрами `?`;
- защита от подбора кода: не больше 5 неверных попыток в минуту с одного IP;
- вход действует 7 дней, права (админ, каналы, личные чаты) проверяются на сервере;
- чужая почта и настройки не отдаются другим пользователям.

Подробно — в разделе «Безопасность» файла [ДОКУМЕНТАЦИЯ.md](ДОКУМЕНТАЦИЯ.md).
