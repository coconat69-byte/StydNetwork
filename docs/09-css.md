# 9. `css/` — стили

[← Оглавление](README.md)

Четыре файла подключаются в порядке «от общего к частному»:

| Файл | Что в нём |
|---|---|
| `variables.css` | CSS-переменные: цвета, шрифт, размеры. Светлая и тёмная тема |
| `base.css` | сброс стилей браузера, шрифт, полосы прокрутки, какой экран виден |
| `components.css` | элементы, которые встречаются на разных экранах |
| `screens.css` | каждый экран отдельно + планшет и телефон |

Названия классов — по **БЭМ**: `блок__элемент--модификатор`.
- `chat-item` — блок (чат в списке);
- `chat-item__name` — его элемент (название);
- `btn--primary` — модификатор (вариант кнопки).

Состояния — классами `is-…`: `is-active` (выбранная вкладка, открытый чат, видимый экран), `is-chat-open` (телефон: открыта переписка).

## `variables.css` — переменные и темы

```css
:root {
  --accent: #2563eb;
  --bg: #f8fafc;
  ...
}
[data-theme="dark"] {
  --accent: #3b82f6;
  --bg: #0f172a;
  ...
}
```
- `:root` — значения для светлой темы.
- `[data-theme="dark"]` — те же переменные с другими значениями. Атрибут `data-theme` на `<html>` ставят `theme.js` и `setTheme`. Все остальные файлы пишут не `#2563eb`, а `var(--accent)` — поэтому тема меняется мгновенно и везде сразу.

| Группа | Переменные |
|---|---|
| Шрифт | `--font` — Inter, а если не загрузился — системный |
| Акцент (синий) | `--accent`, `--accent-hover`, `--accent-light` (светлый фон), `--accent-muted`, `--accent-gradient` |
| Фон и текст | `--bg` (страница), `--bg-elevated` (карточки, панели), `--bg-hover`, `--bg-active`, `--border`, `--text`, `--text-secondary`, `--text-muted`, `--shadow`, `--shadow-md` |
| Статусы | `--online` (зелёный), `--offline`, `--danger`, `--danger-bg` |
| Типы чатов | `--type-channel`, `--type-group`, `--type-direction`, `--type-course`, `--type-flood`, `--type-dm` |
| Размеры | `--topbar-h` (высота шапки, 56px), `--radius`, `--radius-sm`, `--max-w` (1440px — максимальная ширина сайта) |

На телефоне в `screens.css` добавляется `--tabbar-h` — высота нижнего меню (60px).

## `base.css` — основа

| Правило | Зачем |
|---|---|
| `*, *::before, *::after { box-sizing: border-box; margin: 0; padding: 0; }` | убрать отступы браузера; ширина элемента считается вместе с рамкой и отступами — так проще считать размеры |
| `html { font-size: 15px; }` | базовый размер; `rem` в остальных файлах считаются от него |
| `color-scheme: light / dark` | полосы прокрутки и встроенные поля браузера тоже в цвет темы |
| `body { font-family: var(--font); background: var(--bg); color: var(--text); }` | шрифт и цвета страницы |
| `scrollbar-width: thin; scrollbar-color: ...` | тонкие полосы прокрутки |
| `button, input, select, textarea { font: inherit; color: inherit; }` | поля и кнопки берут шрифт страницы, а не свой браузерный |
| `button { cursor: pointer; border: none; background: none; }` | «голая» кнопка без браузерного оформления |
| `img { display: block; max-width: 100%; }` | картинки не вылезают за родителя и без щели снизу |
| `[hidden] { display: none !important; }` | атрибут `hidden` прячет всегда — даже если элементу в CSS задан `display: flex` |
| `.app { max-width: var(--max-w); margin: 0 auto; }` | сайт по центру и не шире 1440px |
| `.app-shell, .logged-in #screen-auth { display: none; }` и `.logged-in .app-shell { display: block; }` | **вход или приложение**: решает класс `logged-in` на `<html>` |
| `.screen { display: none; min-height: calc(100vh - var(--topbar-h)); }` и `.screen.is-active { display: block; }` | виден только активный экран; шапка + экран = ровно высота окна, поэтому футер ниже и виден только при прокрутке |
| `.icon` | размер SVG-иконок 20×20 |
| `[data-theme="light"] .icon--moon, [data-theme="dark"] .icon--sun { display: none; }` | на кнопке темы видна только одна иконка |
| `.muted`, `.link` | мелкий серый текст и текст-ссылка |

## `screens.css` — экраны

### Экран входа
`#screen-auth` — сетка из двух колонок `1fr 420px` на всю высоту окна: синяя половина `.auth-brand` (градиент, логотип, описание, список с галочками через `::before`) и белая `.auth-panel` с формой.

### Шапка `.topbar`
`position: sticky; top: 0` — прилипает к верху при прокрутке. `display: flex` в строку: логотип, меню `.topnav`, поиск `.topbar__search` (растягивается `flex: 1`, но не шире 400px), кнопки справа `.topbar__right` (`margin-left: auto` — прижаты вправо).

### Чаты
```css
.chat-layout {
  display: grid;
  grid-template-columns: 320px 1fr 300px;
  grid-template-rows: minmax(0, 1fr);
  height: calc(100vh - var(--topbar-h));
}
```
Три колонки на всю высоту окна под шапкой: список (320px), переписка (всё остальное), информация (300px).

**Почему `minmax(0, 1fr)` и `min-height: 0` у `.chat-main`.** По умолчанию строка сетки и flex-колонка не могут стать **ниже своего содержимого**. Длинная переписка растягивала колонку вниз за пределы окна, и сообщения наезжали на футер. `minmax(0, 1fr)` и `min-height: 0` разрешают колонке быть ниже содержимого — тогда прокручивается только лента сообщений (`.chat-messages { overflow-y: auto; flex: 1 }`), а поле ввода остаётся внизу окна.

| Блок | Что делает |
|---|---|
| `.chat-sidebar` | колонка: заголовок, фильтры, список (`flex-direction: column; overflow: hidden`) |
| `.chat-filter`, `.is-active` | круглые кнопки-фильтры, выбранная — синяя |
| `.chat-list` | `flex: 1; overflow-y: auto` — список прокручивается сам |
| `.chat-item`, `:hover`, `.is-active` | чат в списке; открытый — голубой фон и синяя полоска слева |
| `.chat-item__body { min-width: 0 }` | разрешает тексту сжиматься — иначе длинное превью растянуло бы колонку |
| `.chat-item__name, .chat-item__preview` | одна строка, лишнее — «…» (`white-space: nowrap; overflow: hidden; text-overflow: ellipsis`) |
| `.chat-header` | шапка переписки: кнопка «‹» (скрыта на компьютере), название и подпись |
| `.chat-messages` | лента: колонка с промежутками 16px |
| `.message`, `.message__bubble`, `__author`, `__text`, `__time` | сообщение: аватарка + «пузырь» не шире 75%. `overflow-wrap: anywhere` — длинное слово без пробелов не вылезет за пузырь |
| `.message--own` | своё: справа (`align-self: flex-end`), синее, белый текст |
| `.message--mention` | упоминание моего имени — голубая подсветка |
| `.compact …` | компактный режим (настройка): меньше отступов |
| `.reactions`, `.reaction` | реакции «👍 18» под сообщением |
| `.chat-input`, `__form`, `__readonly` | поле ввода с кнопкой; или серая плашка «только чтение» |
| `.chat-info` | правая колонка, прокручивается сама |

### Профиль
`.profile-layout` — по центру, не шире 720px. `.profile-header` — аватарка и данные в строку.

### Экраны с меню слева (поиск, настройки, админка)
`.side-layout` — сетка `260px 1fr`: меню `.side-nav` (пункты `.side-nav__item`, «Выйти» — красный `--danger`) и содержимое `.side-content`.

### Поиск
`.user-cards` — сетка `repeat(auto-fill, minmax(260px, 1fr))`: столько колонок по 260px+, сколько влезает. `.user-card` — карточка с содержимым по центру; кнопка `margin-top: auto` — у всех карточек кнопки на одной линии внизу.

### Клубы
`.club-cards` — сетка карточек. `.club-card__banner` — синяя полоса с эмодзи. `.club-card__desc` — описание не длиннее двух строк (`-webkit-line-clamp: 2`). `.club-header` — шапка страницы клуба. `.club-chat` — лента чата клуба в рамке, не выше 420px.

### Настройки
`.settings-row` — строка с переключателем справа. `.toggle` — серая «таблетка», кружок рисуется псевдоэлементом `::after`; `.toggle--on` — синяя, кружок сдвинут `transform: translateX(20px)` с плавной анимацией `transition`. `.theme-picker`, `.theme-option` — две карточки выбора темы.

### Админ-панель
`.stat-grid`, `.stat` — карточки с цифрами; `.admin-form` — форма над таблицей; `.actions` — несколько кнопок в ячейке.

## Планшет и телефон (`@media`)

`@media (max-width: …)` — правила внутри действуют, только если окно не шире указанного. Работает это только благодаря `<meta name="viewport" content="width=device-width">` в `index.html`.

### До 1100px (планшет, маленький ноутбук)
- `.chat-layout` — две колонки `280px 1fr`;
- `.chat-info` (панель справа) скрыта.

### До 768px (телефон)

**Переменные и общее**
- `--tabbar-h: 60px` — высота нижнего меню.
- `input, select, textarea { font-size: 16px }` — на iPhone поле мельче 16px при нажатии приближает всю страницу.
- `html.logged-in body { padding-bottom: … }` — место под нижним меню, чтобы оно не закрывало низ страницы и футер. `env(safe-area-inset-bottom)` — отступ под «полоской» на iPhone без кнопки.

**Вход:** одна колонка, описание сверху, форма снизу.

**Шапка:** от логотипа остаётся значок «С» (`.logo > span:last-child { display: none }`), поиск занимает всё свободное место (`min-width: 0` — разрешает ему сжиматься), кнопки плотнее.

**Нижнее меню:** `.topnav` — `position: fixed; bottom: 0` на всю ширину; три кнопки «Чаты / Поиск / Клубы» поровну (`flex: 1`).

**Чаты — «список или переписка»:**
```css
.chat-layout { grid-template-columns: minmax(0, 1fr); height: calc(100dvh - var(--topbar-h) - var(--tabbar-h) - …); }
.chat-main { display: none; }
.chat-layout.is-chat-open .chat-sidebar { display: none; }
.chat-layout.is-chat-open .chat-main { display: flex; }
.chat-header__back { display: grid; }
```
- одна колонка;
- высота — через `100dvh` («динамическая» высота окна, учитывает появляющиеся панели мобильного браузера); строкой выше — запасной вариант `100vh` для старых браузеров;
- без класса `is-chat-open` виден список, с ним — переписка. Класс ставит `showChat(true)` при выборе чата, а кнопка «‹» (`#chat-back`) — `showChat(false)`;
- фильтры — одной строкой с прокруткой вбок;
- сообщения шире (88%), отступы меньше.

**Профиль, клубы:** шапки — в столбик, баннер клуба меньше, клубы — в одну колонку, вкладки прокручиваются вбок.

**Поиск, настройки, админка:**
- `.side-layout { grid-template-columns: minmax(0, 1fr) }` — одна колонка. `minmax(0, …)` здесь важен: без него длинный выпадающий список направлений или строка меню растягивали колонку шире экрана, и появлялась прокрутка вбок;
- фильтры поиска — в две колонки;
- меню настроек и админки — одной строкой с прокруткой вбок, заголовок спрятан;
- карточки людей — по ~150px (две в ряд).

**Футер:** текст и авторы друг под другом; карточки участников клуба — в одну колонку.
