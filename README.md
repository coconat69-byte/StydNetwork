# 🎓 СтудСеть (StudNet)

> **СтудСеть** — студенческая социальная сеть/платформа, созданная для обмена учебными материалами, общения и координации студенческих активностей.

---

## ⚠️ Дисклеймер (О проекте)

- **Некоммерческий статус:** Данный проект является исключительно учебным/пет-проектом и **не предназначен для коммерческого использования** или извлечения прибыли.
- **Цель разработки:** Освоение современных веб-технологий, получение практического опыта проектирования архитектуры приложений, командной работы и работы с Git.
- Проект распространяется «как есть» (as-is) в образовательных целях.

---

## 🚀 Основной функционал

- 👤 **Профили пользователей:** регистрация, авторизация и настройка профиля студента (вуз, курс, факультет).
- 💬 **Общение и сообщества:** чаты, обсуждения предметов, учебных групп и проектов.
- 📚 **База материалов:** публикация и поиск лекций, конспектов и полезных ссылок.
- 📅 **События и дедлайны:** отслеживание расписания мероприятий и учебных задач.

---

## 🛠 Стек технологий

- **Frontend:** React / Vue / HTML5, CSS3, JavaScript (TypeScript) *(выбери нужное)*
- **Backend:** Node.js (Express) / Python (FastAPI / Django) / Go *(выбери нужное)*
- **База данных:** PostgreSQL / MongoDB / SQLite
- **Прочее:** Docker, Git, JWT для авторизации
